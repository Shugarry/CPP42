# CPP42

Exercises from the 42 C++ curriculum (`cpp00` through `cpp09`), covering OOP fundamentals, inheritance, polymorphism, templates, and STL containers in C++98.

Each module (`cppXX/`) contains its exercises (`exYY/`), each buildable independently with its own Makefile:

```bash
cd cpp05/ex02
make
./exercise_name
```
